# Hi-Lo Game

## Spec
High&LowのJavaScript実装
- htmlの画面をJavaScriptで動かす
- ボタンで画面を切り替えてみる
- すべてのhtmlを1htmlファイルに集約し、html表示部分を切り替えることりにより、画面を切り替える
- ボタンで画像を差し替えてみる
- ボタンでテーブルの色を変えてみる
- ボタンでHigh Lowどちらが押されたか出力してみる
- カード52枚をランダムで表示してみる
- カード52枚を、1枚づつ減らしランダムで表示してみる
