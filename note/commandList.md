Option 1: Using Command Prompt (cmd)
Windows features a native tar utility that natively handles .zip archives. Open Command Prompt and run:
- `tar -a -cf output.zip folder_name`
-a: Automatically determines compression based on the file extension (.zip).
-c: Creates a new archive.
-f: Specifies the name of the output archive file.
output.zip: The path and name you want for your compressed 
file.folder_name: The exact folder you want to compress
