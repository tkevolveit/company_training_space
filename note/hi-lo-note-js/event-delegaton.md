# Event Delegation

子要素ではなく共通の親要素にイベントリスナーを1つだけ登録し、子要素で発生したイベントを処理する仕組み
- 親か子要素がなにか検出する


Y.highとlowのボタン処理をまとめる
W.最初条件を付けてhighかlowを振り分けようとしていたが、
親要素から子要素を検出できることが調べて分かった。
（こういった子要素ではなく共通の親要素にイベントリスナーを1つだけ登録し、
子要素で発生したイベントを処理する仕組みをイベント委譲(Event delegation)
というらしい）
T.イベントを処理する仕組みを意識して実装してみる


アルゴリズム:

コンテナに単一のハンドラを置きます
ハンドラの中で – ソース要素 event.target をチェックします
イベントが関心のある要素の中で起きていた場合、イベントを処理します。
