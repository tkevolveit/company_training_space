## `<a>` tag

- attributes
    - `a:link`: User NOT vistied yet
    - `a:visited`: User ALREADY visited
    - `a:hover`: Target links is mouse overed
    - `a:active`: Targets links is clicked.
    - `a:focus`: Target links is focused on it.
- `=blank`: Open new window

URL
- Safariでは日本語のURLを文字コードに変換できる
